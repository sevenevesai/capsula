# Capsula v1.2.0 - Integration Release 🚀

**NEW:** Export your ChatGPT conversations directly to **GitHub** and **Notion** with one click!

---

## What's New in 60 Seconds

### 🐙 GitHub Integration
- Export to **Gists** (public/private) or **Issues**
- Auto-splitting for large conversations (>1MB)
- URL copied to clipboard automatically
- Perfect for version-controlling your AI research

### 📓 Notion Integration
- Create **rich pages** with beautiful formatting
- Choose parent pages or databases
- Code blocks, lists, quotes - all preserved
- Great for building your knowledge base

### 🎯 Key Improvements
- **Message filtering works everywhere** - range selection + content filters now apply to integrations
- **Better modal UX** - no more keyboard focus issues
- **Smart error handling** - helpful messages + auto-retry
- **Privacy-first** - tokens stored locally, optional permissions

---

## Quick Setup

**GitHub:** 30 seconds
1. Generate token with "gist" scope
2. Paste in settings → Test → Save ✅

**Notion:** 1 minute
1. Create integration
2. Share a parent page with it
3. Paste token → Test → Save ✅
